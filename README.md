## Controls:
- `CapsLock` or `Escape` or `Q` to quit the game
- `WASD` to move around
- `Space` to place torch

## Developer's guide:
Here are the instructions for game developers

### Linux prerequisites
Install `make`, `g++`, `sfml` with your favourite package manager

### Windows prerequisites
Find me, I will cry but will setup everything on your pc

Dear Windows users, being the best girl in the world, I know how you can install our game on your pc. 

First, download Visual Studio and install "Разработка классических приложений на C++" and "Средства CMake C++ для Windows" in it. It gives you a chance to use our game.

Second, copy url to the repository and paste it in Visual Studio creating an area to work with our repository. Also change 5th line in CMakeLists.txt (there should be your folder path)

Finaly press F5. Enjoy!   :)

### Make commands
- `$ make` will compile the game and output `game` executable in `build` folder
- `$ make run` will run the game
- `$ make clean` will remove everything from `build` folder
